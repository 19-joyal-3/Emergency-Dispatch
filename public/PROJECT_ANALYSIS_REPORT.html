1. Executive Summary

Kerala Emergency Dispatch is an offline-first emergency coordination, incident reporting, and multi-modal navigation platform tailored for disaster response across Kerala, India. The application is architected to operate under severe network degradation or complete blackouts during monsoons, floods, and landslides.

It combines an on-device Dijkstra pathfinding engine over a bundled topological road network, a local-first IndexedDB database with offline synchronization queuing, edge AI photo classification for triage verification, and live integration with external services (Valhalla routing, Open-Meteo weather, and Supabase authentication).

3. Functional Subsystems Deep-Dive

3.1. Offline Dijkstra Routing & Blockage Avoidance

  • Pre-computed Topology (src/mapData.json): Contains 19 key Kerala hubs (Thiruvananthapuram, Kollam, Alappuzha, Pathanamthitta, Kottayam, Idukki, Kochi, Thrissur, Palakkad, Kozhikode, Wayanad, Munnar, Vadakkencherry, etc.) with bidirectional coordinate geometries.
  • Speed & Terrain Profiles: Edge speeds dynamically account for road class:
    • Ghat corridors (Idukki, Munnar) constrained to 35 km/h.
    • Local link roads capped at 45 km/h.
    • National highways (NH 66, NH 544) weighted for standard travel speeds.
    • Multi-modal profiles: Car (85 km/h), Bus (55 km/h), Walk (5 km/h).
  • Active Blockage Rerouting: When an edge is marked blocked (e.g. flood or landslide), the solver actively excludes it and calculates alternate detours in milliseconds.
  • Voice Navigation: Spoken turn-by-turn guidance synthesized via HTML5 SpeechSynthesis.

3.2. Incident Management & Automated Dispatch

  • Categorization: Dedicated schemas for Flood, Fire/Landslide, Medical Emergency, and Traffic Blockages with priority ratings (Critical, High, Medium, Low).
  • Responder State Machine: Units (Ambulance Alpha, Fire Engine Beta, Rescue Boat Gamma) with live coordinates, operational statuses, and simulated movement along calculated routes.
  • Sensory Warnings: Multi-frequency siren synthesizer built on the Web Audio API (AudioContext) and mobile haptic pulses (navigator.vibrate).

3.3. Client-Side AI Photo Verification

  • Dynamically evaluates user-submitted disaster photographs directly in the browser via TensorFlow.js MobileNet.
  • Checks predictions against tactical keyword profiles:
    • Flood: river, floodwater, stream, canal, waterfall, dam
    • Landslide: landslide, rockslide, mudslide, debris, cliff, mountain
    • Fire: fire, flame, smoke, blaze
    • Medical / Crash: ambulance, crash, wreck, collision, stretcher
  • Eliminates false reports before deploying limited emergency personnel.

3.4. Live Weather & Evacuation Hub Logistics

  • Weather Hazard Engine: Live Open-Meteo forecasts generate threat levels (danger, caution, safe) with dynamic HTML5 canvas weather overlays (rain particles, storm flashes, fog).
  • Shelters Manager: Tracks designated relief camps across Kerala districts, monitoring total capacity, occupancy percentages, and inventory of food, clean water, medical packs, and blankets.
  • Bus Fleet ("Bustle"): Real-time monitor of public KSRTC and private bus lines across Kerala with station progression tracking.

4. Codebase Health & Technical Debt Assessment

⚠️ Critical Bug Identified in Service Worker (public/sw.js:23)

In public/sw.js on line 23, variable request is referenced directly instead of event.request:

// Current Line 23:
const isPmtilesRangeRequest = request.headers.has('range') && ( ... );

// Required Correction:
const isPmtilesRangeRequest = event.request.headers.has('range') && ( ... );

This causes an uncaught ReferenceError: request is not defined whenever range queries are evaluated by the worker.

⚠️ Monolithic Architecture in src/App.jsx (5,433 Lines)

The entire application UI, Leaflet lifecycle, Web Audio, SpeechSynthesis, AI models, modals, tabs, and timers are housed in a single component. Splitting this into modular components will significantly reduce complexity and prevent redundant re-renders.

ℹ️ Single Bundle Chunk Size Warning (>850 kB)

Vite's build output produces a single JavaScript bundle of 858 kB (248 kB gzip). Code-splitting secondary views (Business Directory, Shelter Hubs, Admin Console) via React.lazy() will optimize initial load times on mobile networks.
